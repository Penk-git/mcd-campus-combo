# 演示视频分镜脚本（目标 60–75 秒）

> 录制方式：电脑浏览器 + 手机各录一段，按分镜剪辑即可。录屏建议 1080p、鼠标动作放慢。
> 全程口播词已写好，照读即可（总字数 ~200 字，正常语速刚好 60–70 秒）。

## 分镜表

| # | 时长 | 画面（录什么） | 口播词 |
|---|---|---|---|
| 1 | 0–5s | 浏览器打开 GitHub 仓库首页 1 秒 → 切到 demo 页面加载完成 | 「这是我为麦当劳开发者大赛做的——麦麦校园搭子，专治学生党吃饭选择困难。」 |
| 2 | 5–14s | demo 页：点「选城市」→ 选兰州 → 🏪门店下拉框自动填充 | 「它不是编数据的玩具。选个城市，它自动搜出你身边的麦当劳门店——每一家都是官方真实门店。」 |
| 3 | 14–24s | 点一个场景 chip（如「考试周补能量」）→ 预算改 25 → 点「算一下」→ Top3 结果卡出现 | 「选场景、给预算，3 秒出 Top3 凑单方案。注意看：价格、热量、蛋白质全部来自麦当劳官方 MCP 实时接口。」 |
| 4 | 24–34s | 鼠标指向结果卡上的「每日参考 41%」和底部营养解读行 | 「它还会说话：这份多少个鸡蛋的蛋白、达每日参考多少，考试周、夜宵、控卡，每个场景的理由都不一样。」 |
| 5 | 34–44s | 往下滑到 🎟️ 真实优惠面板 → 点开一张券的详情弹窗 → 关闭 | 「下面这个优惠面板也是真的：免费薯饼、买一送一，全部来自官方接口，点开能看详情，组合自动帮你用上券。」 |
| 6 | 44–54s | 切手机录屏：手机浏览器打开同一网址，横滑操作、点门店、看结果卡 | 「手机打开一样流畅——移动端专门适配过，宿舍躺床上就能凑单。」 |
| 7 | 54–62s | 切回电脑：把浏览器定位改到其他城市（或刷新看「实时」数据源行）→ 结果变化 | 「换个城市，门店、菜单、价格全跟着变。这就是 MCP 的意义：一个助手，全国通用。」 |
| 8 | 62–70s | 定格 GitHub 仓库页 + Star 按钮特写 | 「数据真实、开箱即用、代码全开源。觉得有用的话，去 GitHub 给我点个 Star——谢谢！」 |

## 录制注意
- 第 2、7 镜依赖实时后端，**白天门店营业时段录**（避开 0:00–5:00 深夜）；若遇「网络波动」提示，点那行字重试即可（录进去也无妨，反而真实）。
- 第 6 镜手机录屏前先强刷一次（Ctrl+F5 / 清缓存），确保是最新版。
- 录完检查：画面里不要出现你的真实定位精确坐标、任何 Token/密钥。
- 字幕：把口播词打成字幕更稳（评委可能静音观看）。

## 一句话版本（发短视频平台用）
「预算 20 块在麦当劳怎么吃最值？我写了个工具，选场景给预算，3 秒出方案，数据全部来自麦当劳官方接口——开源，链接在评论区。」
